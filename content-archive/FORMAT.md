# Archive File Format (content only — NO JSX/CSS/classes/animation)

Each page .md uses:

# <Page name> · route: /<path> · source: <file(s)>

## Meta
- Title: ...
- Description: ...

## Section: <name/eyebrow>
- Heading: ...
- Subheading: ...
- Body: ...
- Bullets: - ...

## CTAs
- <label> → <destination>

## Features / Services / Industries
- <name>: <description>

## Statistics
- <number> — <label>

## FAQs
- Q: ... / A: ...

## Testimonials
- "<quote>" — <name>, <role>

## Forms
- <field label> (placeholder) — submit: <text>

Rules: Capture ALL human-readable business text verbatim. Omit only pure UI/code
(class names, imports, style values, animation configs). If a section has no
items for a heading, omit that heading.

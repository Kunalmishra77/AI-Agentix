PART 1 — BRAND IDENTITY & DESIGN SYSTEM
1.1 — Logo Analysis & Brand DNA
The AGENTIX logo communicates exactly what this brand stands for:
The brain icon rendered in orange — intelligence, AI, neural networks, cognitive power
Heavy geometric sans-serif letterforms in navy — authority, precision, trust, scale
Orange accent on the 'i' dot and the 'A' — the brand's spark of intelligence embedded in structure
Black background version shows confidence — this brand isn't shy
The combination signals: powerful, intelligent, modern, Indian yet globally competitive
Design DNA extracted from logo:
Orange is the energy — it activates, energises, draws the eye to action
Navy is the authority — it grounds, stabilises, builds trust
The brain motif is the visual anchor — it should echo subtly in patterns, textures, backgrounds
Geometric precision — no soft curves, no playfulness, sharp confident forms
Dark backgrounds elevate this brand far more than light ones

1.3 — Typography System
Display / Headline Font:
Syne Bold / Syne ExtraBold — Google Fonts
↳ Why: Geometric, confident, futuristic without being clichéd. The sharp angles echo the logo's precision. Unmistakable at large sizes. Pairs perfectly with the AI/tech positioning.
Body / UI Font:
DM Sans Regular / Medium / SemiBold — Google Fonts
↳ Why: Clean, highly legible, modern without being generic. Works beautifully at small sizes for body copy, labels, and UI elements. The slight geometric quality harmonises with Syne.
Accent / Number Font:
Bebas Neue — Google Fonts (for large stat numbers only)
↳ Why: Creates massive impact for the 200+ clients, ₹50Cr+ stat sections. The condensed, all-caps letterforms add drama to numbers.

SM components (cards, pills): 16px / 20px / 24px padding
MD sections (feature rows, testimonials): 80px top/bottom padding
LG sections (hero, journey phases): 120px top/bottom padding
XL sections (dark full-bleed backgrounds): 160px top/bottom padding
Component Spacing Rules:
Between section headline and body: 24px
Between eyebrow label and headline: 12px
Between headline and CTA: 40px
Card internal padding: 32px all sides
Card gap in grid: 24px
Nav height: 80px (collapses to 64px on scroll)
1.5 — Border Radius & Shape Language
Buttons: 8px border-radius — slightly rounded, never pill, never sharp
Cards (standard): 16px border-radius
Cards (feature, large): 24px border-radius
Image containers: 16px border-radius
Pills / Tags: 100px border-radius (full pill)
Input fields: 10px border-radius
Icon containers: 14px border-radius (square-ish, slightly rounded)
↳ Shape language philosophy: Confident but approachable. No hard 0px squares (cold, corporate). No full circles on non-circular elements (too playful). The 16-24px card radius is the sweet spot for premium tech.

1.7 — Motion & Animation System
Animation Philosophy:
Every animation must serve a purpose — either communicating the intelligence of the system, guiding the user's attention, or rewarding interaction. No decorative spinning or bouncing. Animation = intelligence made visible.
Page Load Sequence:
Nav slides down from top: 0ms delay, 400ms ease-out
Hero eyebrow label fades in: 100ms delay, 500ms fade
Hero headline: words animate in sequentially — 200ms stagger per word, 600ms duration
Hero subheadline: 800ms delay, 400ms fade-up (translateY 20px → 0)
Hero CTAs: 1100ms delay, 400ms fade-up
Hero stats bar: 1400ms delay, 600ms fade-up
Scroll-Triggered Animations:
Section headlines: fade-up + slight scale (0.95 → 1.0), 600ms
Cards: staggered fade-up with 80ms delay between each card
Stat numbers: count-up animation triggered on viewport entry
Images: subtle zoom-in from 1.05 → 1.0 as section enters viewport
Industry logos: fade-in with left-to-right stagger
Hover Microinteractions:
Primary CTA button: translateY -2px + box-shadow deepens, 200ms
Cards: translateY -8px + box-shadow increase + subtle orange border glow, 250ms
Nav links: orange underline slides in from left, 200ms
Industry icons: scale 1.0 → 1.08, orange glow appears below, 200ms
Social links: rotate 10° + scale 1.1, 200ms
Logo: subtle orange pulse on hover, 300ms
Continuous Ambient Animations:
Hero background: very slow mesh gradient shift (20s loop) — feels alive without being distracting
Brain/neural network particle system on hero: subtle floating nodes connected by faint lines
Stats section: orange glow pulses on numbers (3s loop, very subtle)
CTA buttons: gradient background shifts slowly (4s loop)

3.4 — Section Layout Patterns
Pattern A — Dark Intro / Light Detail (most common):
Dark hero → Light feature section → Dark social proof → Light process → Dark final CTA
Pattern B — Eyebrow Label → Headline → Body → CTA:
Every content section follows this exact hierarchy. Orange uppercase eyebrow label (12px) → Syne Bold headline (48px) → DM Sans intro (18px) → Feature content → Optional CTA link.
Pattern C — Asymmetric 60/40 split:
Text block takes 60% for reading comfort. Visual takes 40%. They alternate sides between sections to create rhythm.
Pattern D — Full-bleed colour sections:
Used for stats, CTAs, and highlights. Orange or deep navy stretching edge-to-edge with generous vertical padding (160px). These are 'punctuation' sections — they interrupt the scroll rhythm to make an impact.

PART 7 — DESIGNER'S QUICK REFERENCE CARD
COLOURS AT A GLANCE
Primary Action       Authority / Structure       Light Sections
#E8631A Orange       #1A2B4A Navy          #F8F6F2 Off-White
FONTS AT A GLANCE
HEADINGS → Syne (Bold 700 / ExtraBold 800) from Google Fonts
BODY TEXT → DM Sans (Regular 400 / Medium 500 / SemiBold 600) from Google Fonts
BIG NUMBERS → Bebas Neue (Regular 400) from Google Fonts
DESIGN RULES — NEVER BREAK THESE
Never put orange text on an orange background
Never use pure white (#FFFFFF) as a page background — always use Off-White #F8F6F2 for light sections
Never use more than 3 fonts on any page
Never centre-align body paragraphs (only headlines and stat numbers)
Never use gradients on text except the hero headline — it cheapens the brand
Always include the eyebrow label (orange, uppercase, 12px) above every major section headline
Always end every page section with a clear next action — CTA link or button
Dark sections (navy) always have lighter text. Never dark text on dark background.
Orange is for action, energy, highlights — not for large body text areas
SECTION BACKGROUND ROTATION (follow this order for visual rhythm)
1 — Deep Navy / Near Black (hero or high-impact opener)
2 — Off-White #F8F6F2 (feature content)
3 — Deep Navy (social proof or testimonials)
4 — Off-White (process or how-it-works)
5 — Orange Gradient (stats / ROI strip — full bleed)
6 — Deep Navy (final CTA)
Repeat with variations. Never two consecutive same-background sections.
